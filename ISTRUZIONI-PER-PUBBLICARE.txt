===========================================================
LABORATORIO DIGITALE DI SCIENZE NATURALI
Istruzioni per la pubblicazione sul sito della scuola
===========================================================

CHE COS'È
----------
Un sito didattico di scienze naturali per il liceo scientifico delle
scienze applicate. Raccoglie diverse "stazioni": simulazioni e
strumenti da usare in classe e a casa. Si usa dal computer e dal
telefono, senza installare nulla e senza registrarsi.

Autore: Andrea Zanellati
Versione online già funzionante, per vedere com'è fatto:
https://andreazanellati-pixel.github.io/hackathon-ai-docenti


COSA CARICARE
-------------
Si carica TUTTA la cartella, mantenendo la struttura, sottocartelle
comprese. Questa è la struttura:

    index.html          la pagina iniziale, punto d'ingresso
    stile.css           l'aspetto grafico, comune a tutto
    comune.js           codice condiviso
    home.js             costruisce la pagina iniziale
    stazioni.txt        l'elenco delle stazioni

    stazioni/
        detective/               index.html, detective.js, casi.txt
        sistema-internazionale/  index.html, si.js, si.txt
        convertire/              index.html, unita.js, unita.txt

Man mano che si aggiungono stazioni, compaiono nuove sottocartelle
dentro "stazioni". Il resto non cambia.

Il file da aprire è index.html nella cartella principale.

Gli altri file presenti (README.md, CLAUDE.md, prompt-da-usare.md,
questo stesso file) riguardano il lavoro di preparazione e si possono
ignorare.

IMPORTANTE: i nomi delle cartelle e dei file non vanno cambiati, e
vanno rispettate maiuscole e minuscole. Il server di GitHub distingue
"Casi.txt" da "casi.txt", il computer di casa no: un file rinominato
funziona in locale e si rompe una volta pubblicato.


REQUISITI TECNICI
-----------------
Sito completamente statico: solo HTML, CSS e JavaScript.

    - NON serve PHP
    - NON serve un database
    - NON serve alcuna compilazione o installazione
    - NON ci sono librerie esterne da scaricare
    - NON vengono contattati server esterni

Funziona su qualsiasi hosting, anche il più semplice.


ATTENZIONE: UN SOLO PUNTO DELICATO
----------------------------------
Il sito DEVE essere servito da un server web, cioè raggiunto da un
indirizzo che comincia con http:// o https://.

Se apri index.html con un doppio clic dal disco, la pagina si vede ma
resta vuota: per motivi di sicurezza i browser non permettono a una
pagina aperta in quel modo di leggere gli altri file della cartella, e
i contenuti stanno appunto in file di testo.

Caricato su un sito qualsiasi, funziona senza problemi.

Se il sito della scuola usa un CMS (WordPress, Joomla, Drupal), la via
più semplice è caricare la cartella via FTP in una sottocartella - per
esempio /scienze/laboratorio/ - e linkarla da una pagina del sito.
Inserire i file dentro un articolo del CMS di solito non funziona.


QUANDO ARRIVA UN AGGIORNAMENTO
------------------------------
Si sostituiscono i file cambiati, tenendoli nelle stesse cartelle.

Dentro il sito c'è un numero di versione che viene aumentato a ogni
aggiornamento: serve a costringere i browser a riscaricare i file. Per
questo, quando arriva un aggiornamento, vanno sostituiti ANCHE i file
index.html indicati, non solo quelli con le modifiche: sono loro a
contenere il numero nuovo.


PRIVACY
-------
Il sito non raccoglie e non trasmette alcun dato.

    - nessun cookie
    - nessun sistema di statistiche o tracciamento
    - nessuna risorsa caricata da server esterni
    - nessun dato personale nei contenuti: gli esempi parlano di
      persone inventate
    - punteggi e preferenze restano nel browser di chi usa il sito e
      non escono dal suo dispositivo

Non è quindi necessaria alcuna informativa aggiuntiva oltre a quella
generale del sito della scuola.


COME SI MODIFICANO I CONTENUTI
------------------------------
I file .txt si aprono con il Blocco note e contengono le istruzioni
scritte in cima. Si modifica il testo, si salva, si ricarica la pagina:
non serve toccare il codice.

Importante: vanno salvati con codifica UTF-8, altrimenti le lettere
accentate si rovinano. Nel Blocco note di Windows si sceglie in
"Salva con nome", nel menu a tendina "Codifica".

Se una riga viene scritta male il sito non si blocca: la salta e
segnala in alto quale riga rivedere.


IN CASO DI PROBLEMI
-------------------
Se compare l'avviso "Non riesco a leggere il file ...", vuol dire quasi
sempre una di queste tre cose:

    1. la pagina è stata aperta dal disco invece che dal server
    2. i file non sono stati caricati tutti, oppure la struttura delle
       cartelle non è stata rispettata
    3. un nome di file o di cartella è stato cambiato, anche solo
       nelle maiuscole
