IL DETECTIVE DEGLI ESPERIMENTI
Istruzioni per la pubblicazione sul sito della scuola
===========================================================

CHE COS'E'
----------
Un sito didattico di scienze naturali per una prima di liceo
scientifico, su metodo scientifico e unita' di misura. Si usa dal
computer e dal telefono, senza installare nulla e senza registrarsi.

Autore: Andrea Zanellati
Versione online gia' funzionante, per vedere com'e' fatto:
https://andreazanellati-pixel.github.io/hackathon-ai-docenti


COSA CARICARE
-------------
In questa cartella ci sono anche alcuni file di servizio che NON
servono al sito. I file da caricare sono soltanto questi nove, tutti
insieme, nella STESSA cartella, senza rinominarli e senza creare
sottocartelle:

    index.html      la pagina, punto d'ingresso
    stile.css       l'aspetto grafico
    comune.js       codice condiviso
    detective.js    codice della sezione "I casi"
    unita.js        codice della sezione "Convertire"
    si.js           codice della sezione "Sistema Internazionale"
    casi.txt        i contenuti dei casi
    si.txt          i contenuti sulle unita' del Sistema Internazionale
    unita.txt       le scale di conversione

Il file da aprire e' index.html.

Gli altri file presenti nella cartella (README.md, CLAUDE.md,
prompt-da-usare.md, questo stesso file) riguardano il lavoro di
preparazione e si possono ignorare.


REQUISITI TECNICI
-----------------
Sito completamente statico: solo HTML, CSS e JavaScript.

    - NON serve PHP
    - NON serve un database
    - NON serve alcuna compilazione o installazione
    - NON ci sono librerie esterne da scaricare
    - NON vengono contattati server esterni

Funziona su qualsiasi hosting, anche il piu' semplice.


ATTENZIONE: UN SOLO PUNTO DELICATO
----------------------------------
Il sito DEVE essere servito da un server web, cioe' raggiunto da un
indirizzo che comincia con http:// o https://.

Se apri index.html con un doppio clic dal disco, la pagina si vede
ma resta vuota: per motivi di sicurezza i browser non permettono a
una pagina aperta in quel modo di leggere gli altri file della
cartella, e i contenuti stanno appunto in file di testo.

Caricato su un sito qualsiasi, funziona senza problemi.

Se il sito della scuola usa un CMS (WordPress, Joomla, Drupal), la
via piu' semplice e' caricare la cartella via FTP in una sottocartella
- per esempio /scienze/detective/ - e linkarla da una pagina del sito.
Inserire i file dentro un articolo del CMS di solito non funziona.


PRIVACY
-------
Il sito non raccoglie e non trasmette alcun dato.

    - nessun cookie
    - nessun sistema di statistiche o tracciamento
    - nessuna risorsa caricata da server esterni
    - nessun dato personale nei contenuti: i casi parlano di
      persone inventate
    - i punteggi degli esercizi restano nel browser di chi li fa e
      non escono dal suo dispositivo

Non e' quindi necessaria alcuna informativa aggiuntiva oltre a
quella generale del sito della scuola.


COME SI MODIFICANO I CONTENUTI
------------------------------
I tre file .txt si aprono con il Blocco note e contengono le
istruzioni scritte in cima. Si modifica il testo, si salva, si
ricarica la pagina: non serve toccare il codice.

Importante: vanno salvati con codifica UTF-8, altrimenti le lettere
accentate si rovinano. Nel Blocco note di Windows si sceglie in
"Salva con nome", nel menu a tendina "Codifica".

Se una riga viene scritta male il sito non si blocca: la salta e
segnala in alto quale riga rivedere.


IN CASO DI PROBLEMI
-------------------
Se il sito si vede ma compare l'avviso "Non riesco a leggere il file
casi.txt", vuol dire quasi sempre una di queste due cose:

    1. la pagina e' stata aperta dal disco invece che dal server
    2. i file .txt non sono stati caricati, oppure sono finiti in
       una cartella diversa da index.html
