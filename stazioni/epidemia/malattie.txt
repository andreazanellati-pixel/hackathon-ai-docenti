# ============================================================
# LE MALATTIE
# ============================================================
#
# Ogni riga descrive una malattia contagiosa con i due numeri
# che ne governano la diffusione.
#
# COME SI SCRIVE UNA MALATTIA
# ---------------------------
#
#   nome | R0 | giorni contagiosi | nota
#
# R0       si legge "erre con zero" e si chiama numero
#          riproduttivo di base. È quante persone, in media,
#          vengono contagiate da un malato quando NESSUNO è
#          ancora immune. Se vale 1 l'epidemia si trascina, se
#          vale più di 1 cresce, se vale meno di 1 si spegne.
#
# giorni   per quanti giorni, in media, una persona è contagiosa.
# contagiosi
#
# I valori di R0 qui sotto sono quelli che si trovano nei libri.
# Nella realtà non sono numeri fissi: dipendono da quanta gente
# si incontra, da quanto si sta vicini, dal clima, dall'età.
# Lo stesso morbillo ha un R0 diverso in una città affollata e
# in un paese di montagna.
#
# I numeri si scrivono con la virgola o con il punto.
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Se una riga è scritta male viene saltata e segnalata.
#
# ============================================================
