# ============================================================
# I MARGINI FRA LE PLACCHE
# ============================================================
#
# Ogni riga descrive un posto vero del mondo dove due placche si
# incontrano, e dice di che tipo di margine si tratta.
#
# COME SI SCRIVE UN MARGINE
# -------------------------
#
#   nome | tipo | velocità | profondità dei terremoti | descrizione
#
# tipo   una di queste cinque parole:
#
#          divergente        le due placche si allontanano e in
#                            mezzo nasce crosta nuova
#          oceano-continente una placca oceanica scivola sotto
#                            una continentale
#          oceano-oceano     una placca oceanica scivola sotto
#                            un'altra oceanica
#          continenti        due continenti si scontrano e
#                            nessuno dei due riesce a sprofondare
#          trasforme         le due placche scorrono una accanto
#                            all'altra, senza costruire né
#                            distruggere crosta
#
# velocità   di quanti centimetri all'anno si muovono le due
#             placche una rispetto all'altra. Sono velocità
#             misurate davvero, oggi, con il GPS e con i
#             satelliti: più o meno la velocità con cui
#             crescono le unghie.
#
# profondità fin dove arrivano i terremoti, in chilometri.
# terremoti   È un numero che dice molto: dove una placca
#             sprofonda i terremoti sono profondi anche seicento
#             chilometri, dove le placche si allontanano restano
#             sempre nei primi venti.
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Se una riga è scritta male viene saltata e segnalata.
#
# ============================================================
