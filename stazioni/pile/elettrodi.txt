# ============================================================
# GLI ELETTRODI
# ============================================================
#
# Ogni riga descrive una semireazione di riduzione, cioe' un
# metallo con il suo ione, e il potenziale standard che le
# corrisponde.
#
# COME SI SCRIVE UN ELETTRODO
# ---------------------------
#
#   nome | semireazione | E0 | elettroni | massa molare | quanti ioni | nota
#
# semireazione  si scrive sempre nel verso della RIDUZIONE, cioe'
#               con gli elettroni a sinistra:
#                   Cu2+ + 2 e- -> Cu
#
# E0            il potenziale standard di riduzione, in volt,
#               misurato rispetto all'elettrodo a idrogeno, che
#               per convenzione vale zero. Piu' e' alto, piu'
#               quella sostanza "tira" gli elettroni a se'.
#
# elettroni     quanti elettroni entrano nella semireazione.
#
# massa molare  in grammi per mole: serve per calcolare quanta
#               sostanza si deposita in un'elettrolisi.
#
# quanti ioni   il coefficiente dello ione nella semireazione.
#               Vale 1 per quasi tutti i metalli. Vale 2 per
#               l'idrogeno, perche' la sua semireazione e'
#               2 H+ + 2 e- -> H2.
#
# I numeri si scrivono con la virgola o con il punto. Attenzione
# ai segni: i potenziali negativi vanno scritti con il meno.
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Se una riga e' scritta male viene saltata e segnalata.
#
# ============================================================
