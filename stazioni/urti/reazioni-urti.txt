# ============================================================
# LE REAZIONI DELLA TEORIA DEGLI URTI
# ============================================================
#
# Ogni riga descrive una reazione con i numeri che dicono quanto
# è difficile farla partire.
#
# COME SI SCRIVE UNA REAZIONE
# ---------------------------
#
#   nome | equazione | Ea | Ea col catalizzatore | delta H | orientamento | nota
#
# Ea           l'energia di attivazione, in kJ per mole: la
#              collinetta che le molecole devono scavalcare
#              perché l'urto sia utile. Più è alta, più la
#              reazione è lenta.
#
# Ea col       la stessa collinetta quando c'è un catalizzatore.
# catalizzatore Deve essere più bassa di Ea. Il catalizzatore
#              non cambia il delta H e non sposta l'equilibrio:
#              abbassa soltanto la collinetta, e la abbassa in
#              tutti e due i versi.
#
# delta H      il dislivello fra reagenti e prodotti, in kJ per
#              mole. NEGATIVO se la reazione scalda.
#
# orientamento un numero fra 0 e 1: la probabilità che due
#              molecole che si scontrano siano girate nel verso
#              giusto. Vale 1 per due palline qualsiasi, ma
#              scende molto per molecole grandi e complicate,
#              che devono presentarsi con la faccia giusta.
#
# I numeri si scrivono con la virgola o con il punto.
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Se una riga è scritta male viene saltata e segnalata.
#
# ============================================================
