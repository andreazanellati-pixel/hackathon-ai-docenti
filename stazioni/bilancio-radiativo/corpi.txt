# ============================================================
# I PIANETI E GLI ALTRI CORPI
# ============================================================
#
# Ogni riga descrive un corpo celeste con i numeri che ne
# determinano la temperatura.
#
# COME SI SCRIVE UN CORPO
# -----------------------
#
#   nome | luce ricevuta | albedo | coperte | temperatura misurata | nota
#
# luce ricevuta  quanta energia dal Sole arriva su ogni metro
#                quadro, in watt. La Terra ne riceve 1361. Più un
#                pianeta è lontano, meno ne riceve: Marte 586,
#                Giove appena 50.
#
# albedo         la frazione di luce che il corpo rimanda indietro
#                senza assorbirla, da 0 a 1. La neve fresca
#                rimanda indietro quasi tutto, il basalto scuro
#                quasi niente. La Terra nel suo insieme sta
#                attorno a 0,30, soprattutto per via delle nuvole.
#
# coperte        quanto l'atmosfera trattiene il calore che il
#                suolo irradia. Zero vuol dire nessuna atmosfera,
#                come sulla Luna. La Terra sta attorno a 0,64,
#                Venere oltre cento.
#                Il nome viene dall'immagine: è come contare
#                quante coperte ci sono sopra il pianeta.
#
# temperatura    quella misurata davvero, in gradi centigradi.
# misurata       Serve per confrontare il conto con la realtà.
#
# I numeri si scrivono con la virgola o con il punto.
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Se una riga è scritta male viene saltata e segnalata.
#
# ============================================================
