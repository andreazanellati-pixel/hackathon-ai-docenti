# ============================================================
# GLI INDICATORI
# ============================================================
#
# Un indicatore e' una sostanza che cambia colore in un certo
# intervallo di pH. Serve a capire quando la titolazione e'
# arrivata al punto giusto.
#
# COME SI SCRIVE UN INDICATORE
# ----------------------------
#
#   nome | pH di inizio | pH di fine | colore acido | colore basico
#
# I due colori si scrivono in codice esadecimale, quello che si
# usa sul web: # seguito da sei cifre. Per trovarne uno basta
# cercare in rete "selettore colori esadecimale".
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Attenzione: il # dei colori sta in mezzo alla riga, non
# all'inizio, quindi non crea problemi.
#
# ============================================================
