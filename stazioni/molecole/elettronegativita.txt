# ============================================================
# L'ELETTRONEGATIVITÀ DEGLI ELEMENTI
# ============================================================
#
# L'elettronegatività dice quanto un atomo tira a sé gli
# elettroni del legame. È il numero da cui dipende se un legame
# è polare, e di quanto.
#
# La scala è quella di Pauling: va da 0,7 del francio a 3,98
# del fluoro, che è l'elemento più avido di tutti.
#
# COME SI SCRIVE UN ELEMENTO
# --------------------------
#
#   simbolo | nome | elettronegatività | colore
#
# Il colore serve solo per il disegno, e si scrive in codice
# esadecimale: # seguito da sei cifre.
#
# Le righe che iniziano con # sono commenti: il sito le ignora.
# Attenzione: il # dei colori sta in mezzo alla riga, non
# all'inizio, quindi non crea problemi.
#
# ============================================================
