# ============================================================
# LE SOSTANZE DEL LABORATORIO DELLE PARTICELLE
# ============================================================
#
# Ogni sostanza ha i suoi valori reali: temperature di fusione e
# di ebollizione, calori specifici e calori latenti. Sono questi
# numeri a decidere quanto sono lunghi i plateau della curva di
# riscaldamento, quindi vanno presi da una tabella seria.
#
# COME SI SCRIVE UNA SOSTANZA
# ---------------------------
# Ogni sostanza comincia con la riga [SOSTANZA] e contiene:
#
#   nome:        come si chiama
#   formula:     la formula chimica (facoltativa)
#   colore:      il colore delle particelle, in esadecimale
#   massa molare: in grammi per mole. Serve a calcolare come
#                cambia la temperatura di ebollizione al variare
#                della pressione.
#   fusione:     temperatura di fusione, in gradi Celsius
#   ebollizione: temperatura di ebollizione, in gradi Celsius
#   partenza:    da quale temperatura comincia la simulazione
#
#   calore solido / calore liquido / calore gas
#                calore specifico nei tre stati, in J/(kg·K)
#
#   latente fusione / latente vaporizzazione
#                calore latente, in J/kg
#
#   nota:        una frase che compare sotto la simulazione
#
# ALTRE COSE DA SAPERE
# --------------------
# - Le righe che iniziano con # sono commenti: il sito le ignora.
# - I numeri si scrivono con il punto o con la virgola, come
#   preferisci: 4186 oppure 4186,0
# - Se una riga è scritta male il sito non si blocca: la salta e
#   ti segnala quale riga rivedere.
#
# ============================================================


[SOSTANZA]
nome: Acqua
formula: H₂O
massa molare: 18,0
colore: #3f8fd0
fusione: 0
ebollizione: 100
partenza: -30
calore solido: 2090
calore liquido: 4186
calore gas: 2010
latente fusione: 334000
latente vaporizzazione: 2260000
nota: Guarda quanto è lungo il secondo plateau rispetto al primo: per far evaporare l'acqua serve quasi sette volte l'energia che serve per fonderla. È il motivo per cui il sudore raffredda così bene, e per cui una pentola impiega un attimo a bollire e un'eternità a svuotarsi.
