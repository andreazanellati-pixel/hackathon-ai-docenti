# LE STAZIONI DEL LABORATORIO
# ============================================================
#
# Questo file governa la pagina iniziale. Per aggiungere una
# stazione, o per cambiarne l'ordine, si modifica questo file:
# non serve toccare il codice.
#
# COME SI SCRIVE UNA STAZIONE
# ---------------------------
# Ogni stazione comincia con la riga [STAZIONE] e contiene:
#
#   titolo:      come si chiama
#   icona:       una emoji (facoltativa)
#   disciplina:  Metodo e misura, Chimica, Biologia oppure
#                Scienze della Terra. Le stazioni vengono
#                raggruppate per disciplina, nell'ordine in cui
#                le discipline compaiono in questo file.
#   anni:        in quali anni si usa, per esempio  1 3 4
#   cartella:    il nome della cartella dentro "stazioni"
#   stato:       pronta     se la stazione esiste e funziona
#                in arrivo  se è ancora da costruire: compare
#                nell'elenco ma spenta, e non si può aprire
#   descrizione: una o due righe che dicono che cosa si fa
#
# ALTRE COSE DA SAPERE
# --------------------
# - Le righe che iniziano con # sono commenti: il sito le ignora.
# - Se un testo è lungo puoi andare a capo: le righe che non
#   iniziano con una parola chiave si attaccano alla precedente.
# - Se una riga è scritta male il sito non si blocca: la salta e
#   ti segnala quale riga rivedere.
# - Le stazioni "in arrivo" servono a vedere il piano di lavoro.
#   Quando una viene costruita si cambia solo la parola "stato".
#
# ============================================================
